logo-source.png is the original full WhittWorks logo lockup.
trace_mark.py traces the W with straight polygons, verifies blue and navy overlap, and generates the reusable mark SVG and browser and Apple icons.
The two JPEG share images show the full lockup on white and the traced mark with pale facets on navy.
Regenerate every asset from the repository root with `python3 -I tools/brand/trace_mark.py` using Python 3 and Pillow 11 or later.
